게임 속도가 너무 느려진 문제를 완화했습니다. 게임 내용은 SCM4G v8.08 그대로이고,
게임 실행 쪽 소스는 직전 배포와 같습니다. 바뀐 것은 iOS 앱의 프레임 조절뿐입니다.

## 보내 주신 로그에서 확인한 것

  - 16분 동안 iOS 열 상태는 한 번도 "따뜻함"까지 가지 않았습니다(내내 0).
  - 그런데 게임은 대부분 초당 15프레임(정상의 1/4)으로 돌았습니다.
    CPU 상한(코어 하나의 30%)이 너무 낮아 하한값 15프레임에 붙어 있었습니다.
  - 프레임 하나에 기기에서 25~65 ms 가 걸렸습니다. PC 에서 같은 게임은
    3~5 ms 라서, 기기가 예상보다 훨씬 느리게 돌고 있습니다. 원인은 아직
    모릅니다(CPU 가 쉬는 시간이 많아 iOS 가 클럭을 낮췄을 가능성이 있습니다).

## 바뀐 것

  1. CPU 상한을 올렸습니다.
       평소 30% -> 50%, 따뜻함 22% -> 30%, 뜨거움/저전력 15% (그대로)
     프레임이 8 ms 이하로 가벼우면 예전처럼 60프레임으로 돕니다.

  2. 로그에 두 가지를 더 남깁니다.
       cpu        : 에뮬레이션이 실제로 CPU 를 쓴 시간 비율
       speed test : 30초마다 같은 계산을 돌려 잰 시간. 이 값이 커지면
                    기기가 클럭을 낮춰 느리게 돌고 있다는 뜻입니다.
     이 두 값으로 "게임이 무거운 것"과 "기기가 느리게 도는 것"을 구분할 수
     있습니다.
