던전을 고를 수 있는 두 번째 IPA를 함께 올립니다. 기존 빌드는 그대로입니다.

시계 아이콘을 누르면 빛던전 / 불던전 / 숲던전 목록이 열립니다. 보상까지
구현된 세 개만 넣었습니다.

## 숲으로 고정돼 있던 이유

오프라인 모드가 던전 하나를 자기 코드 안에 박아뒀습니다. 그림 세 장만이
아니라 데이터 경로까지 전부였습니다.

  bmp/UI/dungeon/frst_title.zet            제목
  bmp/UI/dungeon/frst_colloseum_top_01/02  배경 띠
  data/dungeon_frst_type.zet               종류
  data/dungeon_frst_data.zet               던전 데이터
  data/dungeon_frst_title_data.zet         제목 데이터
  data/dungeon_frst_rewardlist.zet         보상 목록
  data/dungeon_frst_master_info_%d_%d.zet  5단계 x 5스테이지

res.dat에는 여섯 던전 세트가 전부 들어 있습니다(기본·fire·dark·frst·
forest·watr, 각 30개 파일). 그림만 바꿨을 때는 배경만 바뀌고 몬스터는
그대로였습니다. 데이터 경로까지 같이 바꾸니 실제로 다른 던전이 됩니다.

병아리 상대가 던전마다 다릅니다. 호스트에서 확인한 값입니다.

  빛던전   베르나
  불던전   샐러맨더
  숲던전   늑대랄프

선택은 저장되고, 던전별 단계 진행도 각각 따로 보관됩니다
(dungeon-progress.bin). 저장값 0/1/2로 새로 시작하면 각각 위 상대가
나오는 것까지 확인했습니다.

## 알고 계셔야 할 제약

**고른 직후에는 제목과 배경만 바뀝니다. 몬스터와 보상은 앱을 다시 켜면
적용됩니다.** 던전 화면이 처음 만들어질 때 데이터 경로를 읽고 그대로
들고 있기 때문입니다. 시작할 때 저장된 선택을 먼저 적용하도록 해놔서,
재시작 후에는 항상 맞습니다.

**병아리·초급·중급·상급·최상급 글자를 눌러도 여전히 반응이 없습니다.**
이건 제가 안 고친 게 아니라 원본 모드부터 그렇습니다. 다섯 칸을 각각
세 높이에서 눌러보고, 단계 플래그를 전부 1로 만들어서도 눌러보고,
꾹 누르기까지 해봤지만 전부 무반응이었습니다. 그 띠에서 반응하는 건
상자뿐이고, 상자는 "최상급 던전을 먼저 클리어하세요."라고 답합니다.
던전을 실제로 도는 건 오른쪽 **빠른듀얼**이고, 상대 이름을 말해주는
것도 그쪽입니다.

## 설치

번들 ID가 달라서 기존 빌드와 **나란히 설치**됩니다. 대신 iOS가 앱마다
저장 공간을 따로 주기 때문에 **세이브는 공유되지 않고 새 게임으로
시작합니다.** 던전 화면까지는 새 게임에서 1분쯤 걸립니다(콜로세움 →
던전). 애플 ID의 주간 App ID 한도는 쓰지 않습니다.

## 검증

  리스트를 안 쓰면 기존과 완전히 동일   던전 화면 2000프레임 + 세이브 70개, 차이 0
  v601   원본 ARM과 120+300프레임, 세이브 60개 일치
  v601m  원본 ARM과 120+300프레임, 세이브 60개 일치
  교차 세션 기준선                      프레임·세이브 모두 기록값과 일치

리스트를 넣은 쪽이 안 넣은 쪽과 한 픽셀도 다르지 않다는 게 이번에
제일 중요한 검증입니다. 터치도 목록 안에서만 받고 나머지는 전부 게임으로
그대로 내려갑니다.
