- 발열 되돌림 (60틱), 카메라 가설 폐기

== 프레임 속도는 원인이 아니었습니다 ==

75틱에서도 카메라는 그대로였고 발열만 늘었습니다.
이번엔 발열 바닥을 60으로 막아 두었으니 "조절 때문에 더 느려진" 것도
아닙니다. 제대로 된 실험이었고, 결과는 음성입니다.

프레임 속도 가설을 폐기합니다. 60틱으로 되돌렸고 발열 단계도
60 / 40 / 20 으로 복구했습니다.

== 증상이 다시 정의되었습니다 ==

"카메라가 늦게 따라온다"가 아니라
"주인공이 화면 중앙에 있지 않다" 입니다. 이건 지연이 아니라 위치입니다.
완전히 다른 문제이고, 제가 지금까지 쫓던 방향이 처음부터 어긋나 있었습니다.

== 확인해서 배제한 것 ==

화면 표시 경로는 정상입니다.
    400x240 을 레터박스(kCAGravityResizeAspect)로 넣고,
    터치 좌표는 정확히 그 역변환으로 되돌립니다.
    여기서 중심이 틀어질 여지는 없습니다.

캔버스 크기도 게임 자체 UI 배치(상단 HUD, 하단 방향패드)와 맞습니다.

== 지금 하고 있는 것 ==

스토리모드 맵에서 주인공의 화면상 위치를 측정했습니다.
시작 방에서는 (136, 84) 로 중앙(200,120)에서 왼쪽 64px, 위 36px 였지만,
그 방은 스크롤이 전혀 없는 좁은 실내라 결론을 낼 수 없습니다.
카메라가 멈춰 있으면 캐릭터가 어디 있든 정상입니다.

야외 맵으로 나가서 길게 걸으며 측정하는 중입니다.
거기서 주인공 위치가
    계속 같은 만큼 치우쳐 있으면  -> 원본 게임의 설계이거나 캔버스 문제
    움직일 때 밀렸다가 돌아오면   -> 카메라 추종 문제
로 갈립니다.
