화면을 자주 바꾸다 보면 UI 가 깨지고 터치가 안 먹히는 문제를 고쳤습니다.
게임은 SCM4G v8.08 그대로입니다.

## 1. 토너먼트 뒤 로비가 멈추는 문제

원인
  일반 듀얼은 결과 화면에서 끝나고, 그 화면을 터치하면 게임이 로비 윗줄의
  상대 캐릭터를 다시 채우고 로비 상태로 돌아갑니다. 토너먼트 듀얼은 결과
  화면 대신 대진표에서 끝나는데, 대진표의 "닫기"는 대진표만 지우고 이 복귀
  처리를 하지 않습니다. 그래서 닫고 나면

    - 윗줄 캐릭터가 비어 있고
    - 캐릭터가 있어야 할 자리를 누르면 응답이 오지 않는 요청이 나가서
      카드가 계속 돌고, 그 뒤로는 어떤 터치도 먹히지 않습니다.

  던전 화면에서 토너먼트를 시작해도 똑같습니다. 제 기능을 빼고 빌드해도
  나오는 게임(모드) 쪽 동작입니다.

수정
  대진표가 닫힌 뒤에도 로비가 듀얼 종료 단계에 남아 있으면, 결과 화면이
  하던 두 가지(상대 줄 다시 채우기, 로비 상태로 전환)를 게임 자체 함수로
  실행합니다. 다음 라운드 듀얼을 시작할 때는 건드리지 않습니다.

## 2. 소울상점 "충전" 버튼

  소울상점 아래의 "충전"을 누르면 게임이 결제 정보를 묻는데, 포팅 쪽에 그
  응답이 없어서 런타임 오류로 게임이 그 자리에서 멈췄습니다. 이제 소울구매
  창이 열리고 뒤로가기로 닫힙니다. (구매 자체는 오프라인이라 되지 않습니다.)

## 3. 스토리 메뉴에 남는 NEW 배지 테두리

  스토리 모드의 메뉴(카드편집/카드조합/.../카드상점)에서 카드상점에 들어갔다
  나오면, 메뉴 아이콘 뒤로 NEW 배지의 빛나는 테두리가 비쳐 보였습니다.
  지난번에는 스토리 맵으로 돌아간 뒤에야 지웠는데, 메뉴로 나오는 순간
  지우도록 했습니다. 지난번에 말씀하신 "카드 상점 갔다가 스토리로 가면 NEW 가
  남는다"가 이 경로였습니다.

## 확인한 것 (PC)

  토너먼트 -> 상대 터치 -> 스토리 들어갔다 나오기 -> 카드상점 -> 소울상점
    콜로세움에서 시작 4바퀴, 던전 화면에서 시작 3바퀴: 매번 로비 정상, 오류 없음
  토너먼트 뒤 상대를 눌러 "좋아요" -> 듀얼 정상 시작
  스토리 맵 -> 메뉴 -> 카드상점 -> 메뉴 -> 스토리 맵 -> 콜로세움: 배지 남지 않음
  소울상점 충전 -> 소울구매 창 -> 닫기
