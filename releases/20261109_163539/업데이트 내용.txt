- 발열: 게임플레이 중 CPU 작업량 누적 19.7% 감소

== 글자 래스터화를 네이티브로 교체 ==

이 게임은 이름, HP, 대미지, 대사, 메뉴까지 항상 글자가 떠 있습니다.
폰트는 1픽셀당 1비트로 저장되어 있고, XFont::_set_DataCopy 가 그것을
비트 단위로 읽으며 켜진 자리에 1(본체), 주변 8칸에 2(테두리)를 씁니다.
게임플레이 중 해석량의 12.6% 로, 가속되지 않은 항목 중 가장 컸습니다.

원본의 비대칭을 그대로 재현했습니다.
    위 / 위왼 / 위오른 / 왼쪽   비어 있을 때만 2를 씀
    오른쪽 / 아래 3칸           무조건 2를 씀
반대로 하면 게임 전체 글자의 테두리 두께가 달라집니다.

결과
    _set_DataCopy   1,754,160 -> 168,000 바이트   (-90.4%)
    게임플레이 전체  13,930,456 -> 12,344,296      (-11.4%)
    처음과 비교      15,365,160 -> 12,344,296      (-19.7%)

해석하는 명령이 줄어든 만큼 CPU 가 일하는 시간이 줄고, 그대로 발열이
줄어듭니다.

== 제가 안 치운 것 하나 수정 ==

100Hz 실험 때 넣은 화면 표시 제한이 그대로 남아 있었습니다.
시뮬레이션과 표시가 둘 다 초당 60으로 같은 주기여서, 미세한 흔들림만으로
프레임 상당수가 마감 직전에 들어와 버려지고 있었습니다.
게임이 이미 다 그려놓은 것을 버리는 것이라 발열은 줄지 않고 화면만
끊깁니다. 시뮬레이션이 표시보다 실제로 빠를 때만 버리도록 고쳤습니다.

== 카메라 보정은 발열 원인이 아니었습니다 ==

같은 구간을 CPU 시간으로 비교했습니다.
    보정 없음  216.5초
    보정 있음  203.6초   (6% 적음)
카메라가 일찍 도착하면 moveMap 이 "도착" 분기로 빠져 맵 경계 계산을
건너뛰기 때문입니다. 되돌릴 이유가 없어 그대로 둡니다.
