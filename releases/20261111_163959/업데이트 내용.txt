v751 '용의 부활' 로 올렸습니다. 지금까지 만든 기능은 전부 그대로 들어갑니다.

## 새 APK에서 하나 고쳤습니다

v751 은 켜자마자 죽었습니다. 카드를 저장하는 코드가 길이 0 으로 memcpy 를
부르는데, 그때 넘기는 주소가 널입니다. C 에서는 길이가 0 이면 주소를 보지
않으므로 완전히 정상인 호출인데, 제 호스트는 주소부터 확인하다 오류로
처리하고 있었습니다.

길이가 0 인 memcpy, memset, memcmp 는 이제 아무 것도 하지 않고 돌아갑니다.
v601 쪽 검증도 다시 돌려 영향이 없는 것을 확인했습니다.

## 던전 기능은 그대로 넘어갑니다

v751 의 모드 영역이 커졌는데도, 던전이 쓰는 자리는 전부 v601 과 같은
주소에 그대로 있었습니다. 터치를 가로채는 코드는 바이트까지 동일합니다.

  bmp/UI/dungeon/frst_title.zet        0x10607d40   같음
  data/dungeon_frst_type.zet           0x10500a24   같음
  dungeon_frst_master_info_%d_%d.zet   0x10500821   같음
  frst-v278-state.bin                  0x10604cb1   같음
  터치 트램펄린                         0x10500100   바이트까지 같음

화면을 알아보는 데 쓰는 시계 아이콘 그림도 v601 과 같은 값이 나옵니다.
그래서 시계 목록, 난이도 창, 도전! 입장, 던전별 진행도가 수정 없이
따라옵니다.

## 검증

  v751 커널 차분      120+300프레임, 세이브 60개 원본 ARM과 일치
  v601 커널 차분      같음 (이번 수정이 기존 버전을 건드리지 않았는지)
  교차 세션 기준선    프레임·세이브 모두 기록값과 일치
  v751 기능 미사용    1,401프레임 + 세이브 59개, 차이 0
  패키지 정적 감사    통과

## 아직 확인 못 한 것

v751 에서 던전 기능을 끝까지 돌려보지는 못했습니다. v751 은 시작할 때
튜토리얼 대화가 길게 붙는데, 제 자동 조작이 그걸 못 넘어가서 던전 화면까지
도달하지 못합니다. 기능 자체는 주소가 같고 v601 에서 증명되어 있지만,
v751 에서 직접 돌려본 증거는 없습니다. 실기에서 던전 한 번 들어가 보시면
바로 확인됩니다.
